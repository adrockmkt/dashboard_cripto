# design.md - Cripto Dashboard Mobile

## Visao de design

O app mobile deve transmitir:

- confianca
- leitura rapida
- precisao analitica
- controle

Nao deve parecer uma adaptacao simplificada do dashboard web. Deve parecer um
produto mobile desenhado para consulta frequente, decisao rapida e leitura
orientada a contexto.

## Principios visuais

- mobile-first
- informacao primeiro, decoracao depois
- contraste alto para leitura de numeros
- poucos elementos competindo por atencao
- cor usada para decisao, nao para enfeite
- cards densos, mas respiráveis

## Principios de UX

- home resumida e acionavel
- cada ativo deve ter uma tela propria forte
- alertas devem ser criados em poucos passos
- portfolio precisa ser o fluxo mais rapido do app
- relatorios precisam ser legiveis em 3 a 5 minutos

## Tom visual

- serio
- tecnico
- moderno
- premium sem parecer excessivo

## Comportamento responsivo

- prioridade total para smartphone
- tablet como adaptacao secundaria
- sem dependencias de layout desktop

## Acessibilidade

- tipografia minima legivel
- contraste adequado para verde/vermelho
- estados nao dependem apenas de cor
- componentes clicaveis com area confortavel

## Regras de navegacao

- bottom navigation para areas principais
- detalhe de ativo como ponto central do produto
- modulos avancados entram por drill-down, nao por excesso de tabs

## Anti-patterns

- mini-dashboard lotado na home
- excesso de graficos pequenos
- cards com texto demais sem hierarquia
- imports visuais do web que prejudiquem o toque e a legibilidade
